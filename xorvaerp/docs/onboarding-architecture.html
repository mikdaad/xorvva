🔒Why it physically can't disturb the architecture
Isolated by design

Every config row is a CompanyEntity → the global query filters wall it off by CompanyId. One client's setup is invisible to all others.

Core is shared & frozen

Accounting, HR, platform code is the same for everyone. No client edits it, so no client can break another.

Engine grows, never forks

The rare code change is a reusable, versioned engine feature — every client benefits. No per-client branches.
